# Support

Use the repository's GitHub community channels:

- Report reproducible bugs in GitHub Issues.
- Ask usage and how-to questions in GitHub Discussions.
- Report vulnerabilities through GitHub private vulnerability reporting in the repository's Security tab, following `SECURITY.md`. Do not open a public issue for a vulnerability.

Do not post API keys, credentials, transcripts, recordings, clipboard contents, crash dumps, or other private or personal data in Issues, Discussions, or other public channels.
